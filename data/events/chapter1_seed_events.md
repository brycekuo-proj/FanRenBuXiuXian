# 第一章種子事件庫

## 事件 001：山中靈草

表面描述：
你在山腰看見一株泛著微光的草，葉片邊緣有淡淡金紋。

背後真相池：

1. 真低階靈草。
2. 瘴氣伴生草。
3. 妖獸誘食草。
4. 宗門藥田外洩。
5. 修士設下的標記陷阱。
6. 有人剛採過，附近留下追蹤印記。

可見徵兆：

- 草旁沒有蟲鳴。
- 土壤被翻過。
- 附近有淡甜味山霧。
- 葉片太整齊，不像野生。
- 石縫裡有獸毛。

選項方向：

- 直接採下。
- 躲遠觀察。
- 做記號回村。
- 找獵戶同行。
- 先檢查足跡。
- 放棄離開。

## 事件 002：遊方散修

表面描述：
村口來了一名青袍散修，說你骨相清奇，願意帶你去見真正的仙途。

背後真相池：

1. 騙盤纏的假修士。
2. 缺試藥凡人。
3. 尋找煉丹材料。
4. 真正落魄好人，但自身難保。
5. 被仇家追殺，帶誰誰倒楣。
6. 看中的不是你，是你家祖傳玉佩。

可見徵兆：

- 他太關心你的年齡、體質與家人。
- 他避談師門。
- 村長收了他的銀子後態度突然變好。
- 他不喝村裡的井水。
- 他鞋底有深泥，但近日無雨。

選項方向：

- 立刻拜師。
- 偷聽他與村長談話。
- 觀察幾天。
- 問他師門來歷。
- 不理他。
- 跟著他離村。

## 事件 003：青雲宗招雜役

表面描述：
青雲宗山下貼出告示，招收雜役，年十六至十八者可試。

背後真相池：

1. 真招雜役，但工作極危險。
2. 靈石搬運缺人。
3. 藥田差事缺替死鬼。
4. 招募只是給地方豪族名額陪跑。
5. 外門師兄私下挑探路炮灰。
6. 極低機率取得殘缺吐納法。

可見徵兆：

- 告示沒有寫工錢。
- 回村的人很少。
- 已有富戶子弟提前住進客棧。
- 招募弟子只問身體，不問家世。
- 山門旁有瘸腿雜役在掃血跡。

選項方向：

- 花錢前往宗門。
- 先去酒樓打聽。
- 留在村中。
- 偷偷混進招募隊伍。
- 賣掉家產準備路費。
- 找回村雜役問話。
