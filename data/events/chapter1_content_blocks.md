# 第一章內容文案池：村外有仙

用途：提供第一章 runtime 與後續擴寫使用的文案素材。此檔為人工可讀版本；機器可讀版本見 `chapter1_implementation.json`。

## 章首語

### 章首 A

你出生在青雲山腳下的柳溪村。

村裡老人說，山外有城，城外有坊市，坊市再往上，才輪得到仙人抬眼看凡人一眼。

你從小聽著這句話長大。你一直以為那是一條路。

後來你才知道，那其實是一層層門檻。

### 章首 B

柳溪村的人都知道山上有仙。

知道是一回事，見過又是另一回事。村裡真正見過修士的人，不是少了一條腿，就是從此不再說夢話。

你今年十六，正是最容易把警告聽成機會的年紀。

### 章首 C

你沒有天靈根，沒有掌門暗中照看，也沒有一枚會說話的戒指。

你有的東西很普通：一副不算結實的身體，幾枚銅錢，一個欠著債的家，還有一個不肯承認自己普通的念頭。

這念頭通常叫志氣。

在修仙界，它也常常叫死因。

## 角色開局文案

### 普通可玩開局

你活到了十六歲。

這在柳溪村不算稀奇，但也不算容易。你會挑水，會砍柴，知道雨前螞蟻搬家，也知道山霧甜起來時不能多聞。

你的父親偶爾會在酒後說，他年輕時曾在山腰見過一道劍光。

他說完後總會沉默很久，摸一摸左腿舊傷。

### 困難但可操作開局

你家欠了鎮上米鋪三兩七錢銀子。

這個數字不大，大到足以讓母親夜裡少點一盞油燈，小到沒有人會覺得你們家值得同情。

你知道，再過一個冬天，家裡總要賣掉一樣東西。

也許是田，也許是你。

### 身體弱勢開局

你小時候發過一場高燒。

郎中說你命硬，活了下來。村裡人也說你命硬，因為他們不知道命硬和身子好其實是兩回事。

你跑不快，氣不長，肩上挑一擔水就會眼前發黑。

但你仍想修仙。

這念頭本身就很危險。

### 少年期直接死亡開局

你三歲那年追著紙鳶跑到溪邊。

大人找到你時，紙鳶卡在柳枝上，你卡在水草裡。

柳溪村後來多了一句話：孩子不能離水太近。

這句話救過很多孩子。

只是救不了你。

墓誌銘：
此地長眠著柳小春，享年三歲。  
他這一生離仙途最近的時候，  
是被村人說成「早登極樂」。

解鎖情報：
不是每一世都來得及選擇。有些凡人的命，連開始都很短。

## 山村少年線

### CH1_VIL_001：母親阻止進山

表面描述：

清晨，你把柴刀磨亮，準備進山。母親坐在灶前，沒有抬頭，只問了一句：

「你是不是又聽誰說山裡有仙草？」

她的聲音不高，卻像鍋底沒燒透的灰，悶著一點火。

可見徵兆：

- 母親昨晚把你的草鞋收進屋裡。
- 柴刀上的缺口被人提前磨平。
- 灶邊多了一碗薑湯，像是早知道你會出門。
- 她提到隔壁王家孩子時，忽然不說話。

選項與結果方向：

1. 聽母親說完。  
   代價：耽誤半日，山裡機緣可能被人搶先。  
   可能結果：母親說出王家孩子上月進山後只帶回一隻鞋。獲得情報「山霧甜時，別用力聞」。

2. 說自己只是砍柴。  
   代價：降低家人信任。  
   可能結果：你帶著柴刀進山，但母親的話卡在耳裡。後續遇見甜霧時，會多一個猶豫選項。

3. 趁她轉身偷偷出門。  
   代價：失去人情保護。  
   可能結果：直接進入山中靈草或夜霧事件；若身體弱，風險提高。

4. 問她王家孩子到底怎麼死的。  
   代價：增加家庭壓力。  
   可能結果：母親哭，父親沉默。你知道王家孩子不是死在妖獸口中，而是笑著走回村、笑著斷氣。

死亡伏筆：
母親越阻止，表示她掌握的不是大道理，而是村裡已經發生過的死法。

死後情報：
凡人的情報多半藏在家人的恐懼裡，不在修士的話術裡。

### CH1_VIL_002：老獵戶的獸足

表面描述：

老獵戶張老七蹲在村口補網。他看見你背著柴刀，忽然叫住你。

「山上最近有東西下來過。」

他把一團灰毛丟到你腳邊。那毛又硬又冷，不像狼，也不像熊。

可見徵兆：

- 灰毛根部有黑色黏土。
- 老獵戶的手背多了三道新疤。
- 他今日沒帶獵犬。
- 村口曬肉架上的肉全收了起來。

選項與結果方向：

1. 花銅錢請他細說。  
   代價：少一筆打聽宗門的錢。  
   結果：獲得獸跡辨識。後續檢查石縫獸毛成功率提高。

2. 幫他搬柴換情報。  
   代價：消耗體力。  
   結果：獲得同樣情報，但身體弱者會帶疲勞進山。

3. 請他同行。  
   代價：欠人情或付銀。  
   結果：降低妖獸守草死亡率，但可能讓獵戶替你受傷，埋入「別人替你死」。

4. 覺得老人膽小。  
   代價：無。  
   結果：保持資源，但後續獸跡 clue 失效。

5. 讓同村少年先去問。  
   代價：降低自身風險。  
   結果：少年可能得到情報，也可能被老獵戶罵走；若後續少年死於獸徑，標記 `transferred_risk`。

墓誌銘：
此地長眠著林二河，享年十六。  
他覺得老人話多。  
妖獸也這麼覺得，  
所以沒有多說。

死後情報：
山裡的獸跡不是知識題，是活人用傷疤換來的地圖。

### CH1_VIL_003：父親的劍光

表面描述：

父親喝了半碗劣酒，忽然說起年輕時的事。

他說自己曾在山腰看見一道劍光，白得像冬天第一場霜。那劍光落下後，半片林子都沒了聲音。

你追問後，他摸著左腿舊傷，只說：

「別把仙人想得太像人。」

可見徵兆：

- 父親左腿在陰雨天會痛。
- 他說起劍光時不興奮，只害怕。
- 他知道青雲宗三字，但從不願進城。
- 家中祖傳玉佩被他藏在米缸底。

選項與結果方向：

1. 細問劍光落在哪裡。  
   代價：父親情緒惡化。  
   結果：獲得青雲山腰舊戰場位置，但該地危險提高。

2. 問青雲宗是否收凡人。  
   代價：父親警覺。  
   結果：獲得宗門招雜役線索。

3. 偷拿祖傳玉佩。  
   代價：家庭信任破裂。  
   結果：後續遊方散修線高風險觸發，因玉佩可能是他真正目標。

4. 假裝沒聽見。  
   代價：錯失情報。  
   結果：保留家庭穩定，但後續宗門與散修事件 clue 減少。

墓誌銘：
此地長眠著周阿石，享年十七。  
他相信仙人也是人。  
仙人沒有反駁，  
只是順手證明了一下。

死後情報：
修士不是比較厲害的人。對凡人來說，他們更接近天災，只是天災會說話。

### CH1_VIL_004：同村少年先走一步

表面描述：

王家阿滿比你早半個時辰出門。

他臨走前對你笑，說如果自己真採到仙草，就分你一片葉子。你看見他的草鞋鞋底綁了紅布，那是他娘怕山裡認不出屍首才縫上的。

可見徵兆：

- 阿滿笑得太用力。
- 他背包裡沒有乾糧。
- 他娘站在門口，手裡捏著香灰。
- 紅布太新，不像裝飾。

選項與結果方向：

1. 追上他一起走。  
   代價：進入高風險山路。  
   結果：兩人互相照應，但也會互相拖累。

2. 等他消息。  
   代價：可能錯失機緣。  
   結果：若他死亡，你獲得 witnessed_death 與山路情報。

3. 阻止他。  
   代價：失去一個早入山機會。  
   結果：成功則增加村中人情；失敗則他仍會出門，但記得你攔過他。

4. 鼓勵他先探路。  
   代價：道德標記。  
   結果：若他遇險，你可能因此避開同死，標記 transferred_risk。

墓誌銘：
此地長眠著王阿滿，享年十六。  
他說採到仙草要分朋友一片。  
後來朋友只分到一隻鞋。

死後情報：
有時候你活下來，不是因為你更聰明，而是因為有人比你早一步犯錯。

## 山中靈草線

### CH1_HERB_001：山腰發光草

表面描述：

你在山腰看見一株泛著微光的草。

葉片邊緣有淡金色紋路，露珠掛在葉尖，像有人把夜色裡剩下的一點星光折進草裡。

你知道，凡人一輩子可能只遇見這一次。

可見徵兆組：

- 草旁沒有蟲鳴。
- 土壤被翻過，像有人重新埋過。
- 石縫裡有灰毛。
- 霧氣有淡甜味。
- 葉片太整齊，不像野生。
- 附近樹幹有很淺的刻痕。

隱藏真相方向：

1. 真低階靈草。  
   不是陷阱，但凡人未必能安全採走。

2. 瘴氣伴生草。  
   草是真的發光，但發光是因為吸了毒瘴。

3. 妖獸誘食草。  
   草是餌，真正的主人在風下。

4. 宗門藥田外洩。  
   靈草是真的，但有宗門標記。

5. 修士設下的標記陷阱。  
   靠近者會被記下氣息。

6. 有人剛採過。  
   你看到的是殘株，附近有追蹤印記。

選項與結果方向：

1. 直接採下。  
   代價：最低，風險最高。  
   結果：可能拿到靈草、毒發、驚動妖獸、被標記、或只採到殘株。

2. 躲遠觀察。  
   代價：耗時，機緣可能被人搶。  
   結果：可揭露一個額外徵兆；若真相是他人追蹤，可能看見第二個人先死。

3. 檢查足跡。  
   代價：需要山野常識。  
   結果：成功可辨識妖獸或人跡；失敗可能踩入陷阱。

4. 找獵戶同行。  
   代價：銀錢或人情。  
   結果：降低獸類風險，但獵戶可能替你受傷或死亡。

5. 做記號回村。  
   代價：機緣可能消失。  
   結果：可帶郎中或獵戶回來；也可能只看到被拔空的土坑。

6. 放棄離開。  
   代價：失去仙緣。  
   結果：大多保命，但若已被標記，放棄也未必安全。

死亡描述：瘴氣

你採下那株草時，指尖像被冰水洗過。

你以為那是靈氣。

回村路上，你開始笑。先是想起母親藏草鞋的樣子，覺得好笑；再想起王阿滿鞋底那塊紅布，也覺得好笑。

等村人找到你時，你靠在樹下，嘴角咧得很開。

他們說你死得很安詳。

只有郎中知道，人的嘴角不該裂到那裡。

墓誌銘：
此地長眠著李小年，享年十六。  
他終於採到了仙草。  
可惜仙草先採走了他的氣。

死後情報：
山裡最香的草，通常不是給人吃的。

死亡描述：妖獸守草

你伸手的瞬間，草後的石縫動了一下。

不是風。

你只來得及看見一隻黃眼睛。下一刻，你聽見自己肋骨碎開的聲音，比柴火在灶裡炸裂還清脆。

那株草沒有被你採走。

它甚至沒有被壓歪。

墓誌銘：
此地長眠著趙阿土，享年十八。  
他終於找到一株靈草。  
可惜那株草也早被別的東西找到了。

死後情報：
真正的機緣旁邊，常常有真正能守住機緣的東西。

### CH1_HERB_002：甜味山霧

表面描述：

山霧從林間漫出來。

它不像普通霧氣那樣腥冷，反而帶著一點甜味，像米糕蒸熟後揭開籠蓋的第一口氣。

你忽然有點餓。

選項與結果方向：

1. 深吸一口辨認味道。  
   代價：無。  
   結果：高風險中毒；若曾聽母親或老人警告，可改為立刻閉氣。

2. 用濕布掩口。  
   代價：需要水與布。  
   結果：降低中毒，但拖慢行動。

3. 繞路。  
   代價：耗時。  
   結果：避開瘴氣，但可能走到獸徑。

4. 退回村中。  
   代價：錯失當日山中事件。  
   結果：大多保命，增加 caution_debt。

墓誌銘：
此地長眠著何秋生，享年十七。  
他說山霧聞起來像米糕。  
他娘後來再也不蒸米糕。

死後情報：
凡人最容易死在不像危險的危險裡。

### CH1_HERB_003：回村只剩土坑

表面描述：

你做了記號，回村找人。

等你帶著老獵戶和郎中趕回山腰時，那株草不見了。原地只剩一個濕濕的土坑，旁邊有幾滴血。

老獵戶蹲下看了很久，說：

「有人比你急。」

選項與結果方向：

1. 追血跡。  
   代價：高風險。  
   結果：可能看到他人死亡，獲得情報，也可能被捲入追殺。

2. 立刻離開。  
   代價：失去機緣。  
   結果：保命，獲得「機緣會吸引比你快的人」情報。

3. 搜附近。  
   代價：耗時。  
   結果：可能撿到殘葉、標記符灰，或觸發陷阱。

4. 指責老獵戶動作太慢。  
   代價：失去人情。  
   結果：後續村中幫助減少。

墓誌銘：
此地長眠著錢小路，享年十六。  
他沒有採到靈草。  
但採到靈草的人，  
把追兵帶到了他面前。

死後情報：
放慢一步可以避開第一刀，也可能剛好撞上第二刀。

## 青雲宗線

### CH1_QY_001：招雜役告示

表面描述：

鎮口貼出青雲宗告示。

紙是好紙，墨是好墨，字寫得端正：

「青雲宗招雜役，年十六至十八者，可試。」

告示底下擠滿了人。有人說這是一步登天，有人說雜役也是仙門裡的人。

你注意到，告示上沒有寫工錢。

可見徵兆：

- 告示沒有寫工錢。
- 回村的人很少。
- 富戶子弟提前住進客棧。
- 招募弟子只問身體，不問家世。
- 山門旁有瘸腿雜役掃血跡。

選項與結果方向：

1. 花錢前往宗門。  
   代價：路費。  
   結果：進入山門測試；若銀錢不足，途中飢餓提高風險。

2. 先去酒樓打聽。  
   代價：銀錢與時間。  
   結果：得知去年招走三十人，只回來兩個，一個不說話，一個少了三根手指。

3. 找回村雜役問話。  
   代價：可能錯過排隊。  
   結果：獲得「別碰發熱的靈石」情報。

4. 留在村中。  
   代價：失去宗門機會。  
   結果：進入凡人苟活或其他事件線。

5. 偷偷混進招募隊伍。  
   代價：高風險。  
   結果：若被抓，可能被打一頓丟下山；若成功，仍只是耗材。

6. 賣掉家產準備路費。  
   代價：家庭壓力巨大。  
   結果：資源增加，但若落選，回村後進入債務結局。

死亡描述：山門台階

青雲宗的台階比你想像中長。

一開始你還數，數到九十七級時，胸口像被石頭堵住。前面的人沒有停，後面的人也不准你停。

你抬頭看，山門還在雲裡。

有人從你身邊跨過去，罵了一句：

「凡人身子。」

那是你最後聽見的話。

墓誌銘：
此地長眠著王狗蛋，享年十七。  
他死在第九十七級台階，  
離修仙夢想尚有三十九級之遙。

死後情報：
宗門不用殺你。它只要把門檻修得夠高，凡人自己就會倒在路上。

### CH1_QY_002：山門初選

表面描述：

招募弟子坐在長桌後，桌上放著一塊青色石頭。

每個少年都要把手按上去。石頭亮了，旁邊的人就記一筆；石頭不亮，就有人把你推到另一隊。

你看見那隊人手裡拿的不是名冊，是扁擔。

選項與結果方向：

1. 老實按上去。  
   代價：無。  
   結果：依靈根與身體抽結果；大多落入雜役或落選。
