# 第一章實作規格：村外有仙

建立日期：2026-09-10

## 章節定位

第一章不是教學章，而是玩家第一次理解「修仙世界不為凡人服務」的死亡篩選器。

玩家以為自己要開始修仙，實際上第一章要證明：

> 凡人連靠近仙途，都需要付出代價。

第一章正式容量目標約五萬字。本次實作先建立可擴充至五萬字的內容骨架與代表性事件資料，後續可持續補文案、真相、死亡與墓誌銘。

## 第一章主題

第一章主題是：自己死。

玩家在第一章的主要體驗不是變強，而是反覆用自己的命校準世界規則：

- 山裡發光的草不一定是機緣。
- 主動說要帶你修仙的人，通常先想從你身上拿東西。
- 宗門不是慈善機構，招雜役往往代表某處需要耗材。
- 保守選項可以保命，但會消耗時間、銀錢、人情與機會。
- 逃避不等於正確，只是把這一世留在凡俗裡。

第一章同時埋入第三章與第五章伏筆：

```text
第一章：自己死
第三章：看別人死
第五章：讓別人死
```

第一章裡玩家偶爾會看見別人先死，或因自己的保守選擇讓別人承擔風險，但此時玩家還沒有能力主動利用這一點。這些都是後面「弒龍者終成惡龍」的早期種子。

## Runtime 內容合約

第一章內容資料應拆成以下層級：

```text
chapter
  ├─ life_profile_pool        # 投胎與少年期條件
  ├─ death_curve              # 越弱越容易死的風險模型
  ├─ world_intel_pool         # 死後世界情報
  ├─ epitaph_pool             # 墓誌銘
  └─ event_lines
       ├─ village_youth       # 山村少年線
       ├─ mountain_herb       # 山中靈草線
       ├─ qingyun_recruitment # 青雲宗線
       └─ wandering_cultivator# 遊方散修線
```

每個事件必須支援：

```text
表面描述
背後真相池
可見徵兆
策略選項
選項代價
結果文本
死亡伏筆
解鎖情報
墓誌銘
跨章伏筆
```

禁止把選項做成固定答案。例如「先觀察」不是萬用正解；在部分真相下觀察會錯失機緣、被人搶先、或讓同行者先死。

## 核心狀態變數

第一章 runtime 至少需要以下狀態：

| 狀態 | 用途 |
|---|---|
| `body` | 身體底子，影響山路、瘴氣、靈壓、搬運等結果。 |
| `silver` | 銀錢，影響打聽、請獵戶、路費、買藥。 |
| `family_debt` | 家中負債，影響是否能拖延、是否被迫賣身或出村。 |
| `village_bonds` | 村中人情，影響老人、獵戶、郎中是否幫忙。 |
| `mountain_lore` | 山野常識，影響辨識獸跡、霧氣、草藥。 |
| `sect_rumor` | 宗門情報，影響青雲宗線判斷。 |
| `injury` | 傷病，累積後會提高後續死亡率。 |
| `caution_debt` | 謹慎造成的時間與機會成本。 |
| `greed_mark` | 貪念標記，影響被散修、師兄、騙子盯上的機率。 |
| `witnessed_death` | 是否看過別人死，用於第三章伏筆。 |
| `transferred_risk` | 是否曾讓別人承擔風險，用於第五章伏筆。 |

## 死亡曲線

第一章死亡不是純骰子，而是由「凡人弱點」與「事件真相」疊加。

```text
死亡風險 = 事件基礎危險
        + 身體弱勢
        + 缺錢造成的錯誤選擇
        + 缺情報造成的誤判
        + 傷病累積
        + 被宗門／散修標記
        - 付出代價取得的情報
        - 合理準備
        - 放棄或延後帶來的避險
```

### 階段目標

| 階段 | 目標感受 | MVP 存活目標 |
|---|---|---|
| 少年期 | 不是每個人都有資格長大 | 約 80% 活過 |
| 第一次聽見仙緣 | 仙緣會引出代價 | 約 55% 踏出村子 |
| 第一次接觸機緣 | 看到好處前先看到危險 | 約 30% 接觸後仍存活 |
| 第一章尾聲 | 活下來也可能失去資格 | 真吐納法約 10%～15% |
| 極罕見上限 | 感氣而非起飛 | 感氣約 3%～5%，引氣入體低於 1% |

## 第一章主事件線

### 1. 山村少年線

用途：建立玩家不是英雄，而是被家庭、身體、年紀、欠債、資訊差限制的普通人。

核心事件：

- 投胎與少年期條件。
- 母親阻止進山。
- 父親曾見過修士的傳聞。
- 村中老人懂山霧。
- 獵戶知道獸足。
- 郎中懂普通草藥但不懂靈草。
- 同村少年先一步消失。

### 2. 山中靈草線

用途：展示機緣不等於能拿。

核心事件：

- 山腰發光草。
- 甜味山霧。
- 沒有蟲鳴。
- 獸毛與翻土。
- 宗門藥田外洩。
- 修士標記陷阱。
- 真靈草但拿了會被追蹤。

### 3. 青雲宗線

用途：展示宗門不是慈善機構。

核心事件：

- 招雜役告示。
- 沒寫工錢。
- 富戶子弟提前住店。
- 回村雜役瘸腿。
- 靈壓測試。
- 搬靈石。
- 藥田差事。
- 外門師兄私下挑探路炮灰。

### 4. 遊方散修線

用途：展示主動提供機會的人，比妖獸更危險。

核心事件：

- 青袍散修入村。
- 骨相清奇話術。
- 村長收銀子。
- 散修避談師門。
- 試藥邀請。
- 祖傳玉佩。
- 仇家追殺。
- 真落魄好人但自身難保。

## 第一章結局類型

第一章不是只用死亡結束，也可以用以下方式結束一世：

- 死亡。
- 殘廢。
- 經脈受損，失去修仙資格。
- 被賣為雜役，進入第二章風險。
- 錯失仙緣，回村凡俗一生。
- 拿到假功法，埋入第三章騙局。
- 拿到殘缺吐納法，但帶傷進入第二章。
- 目睹他人死亡，帶著情報進入下一世記憶池。
- 讓別人先探路而活下來，埋入第五章道德腐蝕伏筆。

## 後續擴寫方式

第一章要擴到五萬字時，不需要推翻資料結構，只要沿以下方向增加內容：

1. 每個表面事件增加更多 hidden truth。
2. 每個 hidden truth 增加 2～4 組可見徵兆組合。
3. 每個選項增加不同狀態下的結果文本。
4. 每種死亡增加墓誌銘與世界情報。
5. 補入更多「別人先死」與「別人替你死」的小事件，讓第三章與第五章主題更早埋入。
