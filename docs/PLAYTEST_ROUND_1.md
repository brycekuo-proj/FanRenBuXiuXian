# 《凡人不修仙》真人輪迴驗收（第一輪）

狀態：**待真人執行，尚無真人樣本**。自動場景圖測試／瀏覽器煙霧測試與真人感受不得混為一談。

## 測試目的與版本

以 `feat/continuity-save-fairness` 功能版本在手機直式瀏覽器測試；目標是判斷玩家是否能從死後情報學到風險判斷，而不是背固定選項；是否願意「再投一世」，以及跨章人物是否令人記得。記錄測試日期、版本 SHA、手機型號／瀏覽器、是否新玩家，避免混用不同版本數據。

建議 5–10 名自願玩家，每人進行 3–5 世，總共至少 20–30 次輪迴。事前告知匿名蒐集遊玩回饋，不錄影、不收取真名、未取得同意不得錄畫面或聲音。測試結束可清理本機 `fanren.continuity.v1` 與 `fanren.reader.v1`，先徵詢玩家是否需要保留存檔。

## 必測操作

1. 首次開頁，試玩一世，調整大字／快速，刷新：場景與字體、速度都應還原。
2. 選擇有貨幣成本的選項，當銅錢／靈石不足，選項應鎖住、說明不足；但扣貢獻的事故懲罰不應阻擋故事前進。
3. 死亡頁刷新兩次：該世只記一次死亡；「再投一世」重置此生資源但保留累積死數與風險殘念；「回到三岔口」同樣不得借屍還魂。
4. 重開新的一世，在相似事件檢查線索／結果可變，前世殘念只能給警告而不能透露應按哪個選項。
5. 工程版 `fanren.html?dev=1&chapter=5` 可測第五章且不覆寫正式玩家存檔。
6. 觀察鄭師兄、梁敬、陳槐、趙醫官、顧十三及第五章隊友的回想文字是否連貫；NPC 死亡不應直接跳玩家墓誌銘。

## 死亡公平性四問（每一類死法均審）

- 有具體因果，而非只有抽到死亡百分比嗎？
- 事前至少存在一項可觀察徵兆嗎？線索真相允許多種合理解釋嗎？
- 玩家可否藉由觀察、準備、付費、延遲、求援或撤退改變風險？保守選擇是否也承受真實代價？
- 死後情報是否提升一般風險認識、而非明示「選 B 就過」？

## 產品目標（尚非已達成測量）

首輪以 **至少 20 次真人輪迴** 作為樣本起點；記錄重新開始意願、死亡覺得有伏筆的比例、閱讀卡住次數、存檔與觸控錯誤數，先觀察再定正式門檻。不要用自動圖測試的 447 個場景／859 條連線當作真人通關率或公平性證據。

## 自動化基線

`node --test tests/continuity.test.cjs`：存檔、資源／命運底牌、死亡去重、NPC 基礎資料、完整場景指向與程式接線。

從專案根目錄啟動 `python3 -m http.server 28765 --bind 127.0.0.1`，另執行 `python3 tools/browser_smoke.py`：Chromium 的讀寫存檔、刷新、偏好、死亡結算、貨幣鎖及工程版隔離。瀏覽器測試不是真人遊玩。
