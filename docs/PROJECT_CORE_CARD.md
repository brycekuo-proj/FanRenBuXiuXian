# 【專案核心卡】

## 專案名稱

《凡人不修仙》

## 一句話定位

一款黑色幽默、短局制的文字 Roguelike 修仙生存遊戲；玩家不是天命主角，而是努力不要死在仙途門口的普通人。

## 玩家實際在做什麼

玩家反覆投胎成不同條件的凡人，在村莊、宗門、坊市、散修與山野機緣之間做判斷：要不要冒險、要不要打聽、要不要花代價換情報、要不要放棄仙緣。

角色會死亡、殘廢、失去修仙資格、回歸凡俗，或在少數情況下真正摸到仙途；玩家保留的不是角色能力，而是對世界風險與規則的理解。

## 核心爽點

不是「選對答案一路飛升」，而是玩家逐漸學會看穿修仙世界的危險：看懂誰在騙人、什麼靈草不能碰、什麼宗門不是在收人、什麼時候逃跑比冒險更聰明。

每一次荒謬但合理的死亡，都留下值得截圖的墓誌銘與下一世可用的常識。

## 它不是什麼

- 不是爽文修仙。
- 不是放置養成。
- 不是靠背事件正解的 Roguelike。
- 不是大地圖探索 RPG。
- 不是抽卡、戰力膨脹、戰鬥刷裝備遊戲。
- 不是「多死幾次就必定變主角」的成功學模擬器。

## 和現有其他專案最大的差異

它是目前最輕量、最適合文字與事件驅動驗證的作品。核心不靠操作手感、複雜美術、戰鬥系統或大量角色，而是靠「死亡是否荒謬又合理」與「玩家是否願意立刻再投一世」。

相較《午夜連線：ECHO》偏敘事推理恐怖、其他遊戲偏玩法或系統建構，《凡人不修仙》更像可快速反覆測試的黑色幽默事件引擎。

## 適合的產品型態

短局反覆挑戰＋章節型內容擴充。

初期適合 Web/PWA 免費 Demo，以分享墓誌銘、死法收藏、再投一世循環驗證留存；若第一章成功，再做四章完整買斷版或低價 Premium Web／App 版。

廣告或去廣告可以在 MVP 驗證後再考慮，但不應先破壞死亡節奏。

## MVP 最小驗證問題

玩家死亡後，會不會覺得「靠，剛剛其實有提示」；並因為不服氣、想驗證新的判斷，而立刻再投一世？

## 目前不該長出的東西

- 築基以上境界。
- 戰鬥系統。
- 大地圖。
- 抽卡與角色收集。
- 多角色隊伍。
- 大量宗門與地區。
- 排行榜、社交、線上功能。
- 商城與複雜付費設計。
- 固定事件正解。
- 會讓玩家靠背答案穩定進主線的攻略式設計。
