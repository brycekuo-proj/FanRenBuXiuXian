# MVP 範圍

## MVP 只驗證第一章

目前不要大幅擴充章節，不做第二章完整內容。MVP 只需要證明：第一章是否能讓玩家死後立刻想再投一世。

## 最小驗證問題

> 玩家死亡後，會不會覺得荒謬又合理，然後不服氣地立刻再投一世？

更具體地說：

- 玩家是否覺得死亡有伏筆？
- 玩家是否覺得下一世可以做出更好的判斷？
- 玩家是否想截圖墓誌銘？
- 玩家是否理解這不是背答案遊戲？
- 玩家是否能接受「不修仙也可能是好結局」？

## MVP 應該包含

- 手機直式文字介面。
- 投胎／生成身分。
- 山村少年基礎開局。
- 少量家境與身體差異。
- 青雲宗、山中靈草、遊方散修三大主線。
- 多種死亡、殘廢、失去資格、回歸凡俗結局。
- 墓誌銘卡片。
- 世界情報解鎖。
- 死亡次數紀錄。
- 再投一世。

## MVP 不應該包含

- 築基。
- 戰鬥系統。
- 大地圖。
- 抽卡。
- 多角色隊伍。
- 商城。
- 線上排行。
- 多宗門開放世界。
- 複雜裝備。
- 長篇主線劇情。

## 第一章必要體驗

玩家應該逐漸理解：

- 仙緣不是免費的。
- 靈草不是看到就能採。
- 宗門不是收容所。
- 散修不一定自由，也不一定善良。
- 逃跑不是怯懦，是凡人的智慧。
- 活得久本身就是天賦。
