# 節奏與存活率目標

## 單局節奏

- 一局平均：30 秒到 2 分鐘。
- 謹慎玩家少數可活到 5 分鐘以上。
- 大部分角色活不到引氣入體。
- 死亡後應該能快速再投一世。

## 長期目標存活率

```text
活過出生／少年期：約 70%
真正踏出村子：約 45%
接觸修仙機緣後仍存活：約 20%
拿到真吐納法：低於 10%
成功感氣：1%～3%
成功引氣入體：低於 0.5%
```

## MVP 初期建議存活率

第一版不要一開始就硬壓到最地獄，否則玩家還沒學會規則前會覺得系統亂殺。

```text
活過少年期：約 80%
踏出村子：約 55%
接觸修仙機緣後仍存活：約 30%
拿到真吐納法：約 10%～15%
成功感氣：約 3%～5%
引氣入體：低於 1%
```

## 調整原則

不能用純隨機殺人壓低存活率。

死亡必須有：

- 因果。
- 伏筆。
- 資訊價值。
- 可供下一世判斷的世界知識。

玩家死後應該覺得：

> 靠，剛剛其實有提示。  
> 我下次不會再這樣做。

而不是：

> 系統亂殺我。
