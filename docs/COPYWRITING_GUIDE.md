# 文案口吻規範

## 核心口吻

黑色幽默、冷淡、古風但不裝腔。像一本殘缺手札在記錄普通人的失敗，不像熱血旁白在鼓勵主角逆襲。

## 可以使用的語氣

- 冷靜記錄。
- 事後補刀。
- 荒謬對比。
- 世界規則的殘酷感。
- 凡人視角的渺小感。

## 避免的語氣

- 太中二。
- 太爽文。
- 太系統化攻略口吻。
- 太像網頁遊戲數值提示。
- 太明顯嘲笑玩家。
- 太直白告訴玩家正解。

## 品牌句

> 修仙本是逆天而行。  
> 但不是每個人，都有逆天的資格。

> 這世上沒有廢物逆襲。  
> 只有活得比別人久的人。

## 文案範例方向

### 正確味道

```text
他終於被宗門看見了。
可惜那天，宗門缺一盞燈。
```

```text
你沒有成仙。
但你活到了六十三歲。
在這個村子裡，這已經很像奇蹟。
```

```text
你死時面帶笑容。
鄰里皆稱其得道，直到聞到異味。
```

### 錯誤味道

```text
你選錯了！下次應該先觀察！
```

```text
恭喜獲得 SSR 天命仙緣！
```

```text
戰力不足，請提升境界後再來挑戰。
```
