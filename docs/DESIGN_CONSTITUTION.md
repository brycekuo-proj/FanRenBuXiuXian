# 《凡人不修仙》核心設計憲法

## 最高原則

> 玩家可以學會世界的危險，但不能學會世界的答案。

《凡人不修仙》不能讓玩家透過死亡背出固定正解。玩家成長的方式不是記按鈕，而是逐漸理解修仙世界的風險、階級、騙局、代價與徵兆。

## 玩家保留的是常識，不是攻略

錯誤示範：

```text
第 1 世選 A 死掉
第 2 世改選 B
第 3 世背出正解
最後穩定進入修仙線
```

這會讓死亡變成試錯成本，玩家最後仍然會靠記答案變成主角，違反本作核心。

正確方向：

```text
上一世被遊方散修試藥害死。
下一世學到：主動收徒的人要提防，尤其太關心你的經脈、年齡、家人與體質時。
但這不代表每個散修都該無視。
```

玩家要學到的是：

- 先觀察。
- 先打聽。
- 看對方要什麼。
- 確認代價。
- 不要把唯一的命交給陌生人。

## 同一事件不能有固定答案

同樣是「山裡靈草」，背後真相必須可能不同：

| 表面事件 | 可能真相 |
|---|---|
| 山裡有靈草 | 妖獸守著 |
| 山裡有靈草 | 宗門藥田外洩 |
| 山裡有靈草 | 前人設下的誘餌 |
| 山裡有靈草 | 真的是低階靈草，但你沒能力辨識 |
| 山裡有靈草 | 靈草無害，附近瘴氣才是殺因 |
| 山裡有靈草 | 有人剛採過，留下追蹤印記 |

因此「直接採」通常很危險，但「觀察三天」也未必安全；可能錯過、被別人發現、耗掉糧食、染病，甚至因年紀增加而失去宗門招收資格。

## 死亡不能直接揭露完整答案

不要寫：

```text
你應該選擇「先去酒樓打聽」。
```

應該寫：

```text
你死於山瘴。直到斷氣前，你才想起村中老人說過：
「春末山霧貼地，聞起來甜，才最毒。」
```

玩家得到的是世界知識，不是按鈕答案。

## 保守選項也要有代價

如果所有安全選擇都只是「你活下來了，但什麼都沒得到」，玩家最後一定會硬賭機緣。

保守可以活命，但要付出代價：

- 錯過宗門招收年齡。
- 消耗糧食或銀錢。
- 家人病情惡化。
- 被村人視為膽小。
- 錯失唯一一次真機緣。
- 活著，但離仙途更遠。

## 冒險選項不能只是純骰子

冒險前應該允許玩家做準備：

- 觀察。
- 打聽。
- 延後。
- 找人同行。
- 付錢買情報。
- 檢查環境。
- 犧牲資源換安全。

玩家可以降低風險，但不能消除風險。

## 不修仙也是合理勝利

《凡人不修仙》必須允許玩家活出比較好的凡人結局：

- 留村當郎中，活到六十歲。
- 在坊市替人抄書，見過很多修士，沒被捲進去。
- 做宗門外圍雜役，雖沒有修為，但攢下家業。
- 當獵戶，知道山裡哪裡不能去。
- 結識一名失意散修，沒學到功法，但保住一家人。

這些不是失敗結局，而是：

> 你沒有成仙。  
> 但你也沒有因為想成仙而變成一具無名屍體。

## 事件設計六問

每個事件進入製作前都要檢查：

1. 這件事是否有唯一正解？
2. 玩家能否靠死一次就背出答案？
3. 保守選項是否永遠安全？
4. 冒險選項是否只是賭骰子？
5. 玩家有沒有能觀察、打聽、延後、付出代價換情報的空間？
6. 即使做對了，是否仍可能因為自己只是凡人而無法得到機緣？
