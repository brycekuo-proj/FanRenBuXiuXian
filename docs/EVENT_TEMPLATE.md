# 事件設計模板

所有事件都要避免固定答案。事件應該以「表面事件＋隱藏真相＋可見徵兆＋代價選項」組成。

## 標準欄位

```text
事件名稱：
事件章節：
表面描述：
背後真相池：
可見徵兆：
玩家選項：
選項代價：
需要條件：
可能結果：
死亡伏筆：
解鎖情報：
墓誌銘：
是否可重複遇到：
是否有固定正解：否
```

## 設計原則

### 1. 表面相同，真相不同

玩家看到的事件名稱或第一段描述可以相似，但背後真相不能固定。

### 2. 選項不等於答案

選項只能代表玩家的策略：冒進、觀察、打聽、付代價、逃避、求助、延後。

### 3. 伏筆要先於死亡

死亡不能像天外飛來。前面要有不完整徵兆，讓玩家死後回想時覺得合理。

### 4. 情報不是攻略

解鎖情報應該描述世界規則，而不是指出正確按鈕。

### 5. 凡人限制永遠存在

即使玩家判斷正確，也可能因為沒有錢、沒有體力、沒有靈根、沒有背景、年紀太大，而無法得到機緣。

## 範例：山中靈草

```text
事件名稱：山中靈草
事件章節：第一章
表面描述：你在山腰看見一株泛著微光的草，葉片邊緣有淡淡金紋。

背後真相池：
1. 真低階靈草。
2. 瘴氣伴生草。
3. 妖獸誘食草。
4. 宗門藥田外洩。
5. 修士設下的標記陷阱。

可見徵兆：
- 草旁沒有蟲鳴。
- 土壤被翻過。
- 附近有淡甜味山霧。
- 葉片太整齊，不像野生。
- 石縫裡有獸毛。

玩家選項：
- 直接採下。
- 躲遠觀察。
- 做記號回村。
- 找獵戶同行。
- 先檢查足跡。
- 放棄離開。

選項代價：
- 觀察耗時間。
- 找獵戶耗錢或人情。
- 回村可能錯失機會。
- 放棄會失去仙緣。

解鎖情報：
山裡最香的草，通常不是給人吃的。
```
