# 墓誌銘系統

## 顯示內容

角色死亡或人生結束時，顯示：

- 名稱。
- 出身。
- 年齡。
- 死因。
- 本世最接近仙途的一刻。
- 黑色幽默墓誌銘。
- 新解鎖世界情報。

## 墓誌銘功能

墓誌銘不是單純死亡畫面，而是本作的分享核心。

它要同時做到：

1. 讓玩家笑或愣住。
2. 讓死亡合理化。
3. 暗示下一世可以注意的世界規則。
4. 讓玩家願意截圖。

## 寫作原則

- 不直接告訴玩家該選哪個選項。
- 可以揭露死因，但不要揭露完整事件真相。
- 儘量有一句可記憶的收尾。
- 可以殘酷，但不要廉價。
- 黑色幽默來自「修仙夢想」與「路人現實」的落差。

## 範例格式

```text
王狗蛋，山村農戶，壽十七。

死因：從青雲宗山門被驅落，頸骨於第九十七級台階折斷。

本世最接近仙途的一刻：
看見青雲宗山門石碑。

墓誌銘：
此地長眠著王狗蛋，享年十七。
他死在第九十七級台階，
離修仙夢想尚有三十九級之遙。

新解鎖世界情報：
宗門的台階，也是宗門篩人的一部分。
```
