# 四章結構規劃

《凡人不修仙》正式版以四章為上限。四章足夠講完整個主題，不讓作品膨脹成普通修仙 RPG。

```text
第一章：我想修仙
第二章：仙門不要我
第三章：修仙界想吃我
第四章：我終於能修了，但我還要嗎？
```

## 第一章：村外有仙

玩家狀態：普通凡人、山村少年、家境與身體條件不穩定。

核心體驗：玩家第一次接觸仙途，學會「機緣不一定是好事」。

主要內容：

- 山村生活。
- 出身與家境。
- 靈根傳聞。
- 青雲宗招雜役。
- 山中靈草。
- 遊方散修。
- 少量開局殺與少年期事故。

## 第二章：山門不渡凡人

玩家狀態：宗門招募者、落選者、雜役、外門邊緣人。

核心體驗：宗門不是慈善機構，進去不代表活下來。

主要內容：

- 靈根測試。
- 雜役選拔。
- 靈石搬運。
- 藥田差事。
- 師兄利用。
- 外門規矩。
- 殘缺功法。

## 第三章：坊市沒有好人

玩家狀態：低階散修邊緣、跑腿、抄書人、商販、小人物。

核心體驗：看懂修仙界真正靠什麼活：情報、錢、逃跑與不要多問。

主要內容：

- 青石坊市。
- 假功法。
- 騙子丹藥。
- 酒樓八卦。
- 落魄修士。
- 高階修士衝突。
- 黑市與滅口。

## 第四章：你還想修嗎

玩家狀態：少數碰到真仙途門檻的人。

核心體驗：第一次真正有機會修煉，但要決定是否值得繼續賭命。

主要結局方向：

- 苟活凡人結局。
- 半吊子散修結局。
- 宗門耗材結局。
- 看破修仙結局。
- 真入仙門極罕見結局。
- 死在成功前一刻。

第四章不是打王破關，而是價值選擇。

> 你知道修仙到底是什麼了。  
> 你還要不要進去？
