# 五章結構規劃

《凡人不修仙》正式版以五章為完整主線骨架，每章目標約五萬字，總文本量約二十五萬字。

這不是要求第一版一次寫完二十五萬字，而是要求所有章節設計、事件資料、伏筆與分支都要按「每章可擴成五萬字」的容量來規劃，不能把第一章做成只夠 Demo 的短章。

```text
第一章：我想修仙
第二章：仙門不要我
第三章：藥谷秘境，機緣皆是殺局
第四章：打了小的，來了老的；但今天的小的是我
第五章：我終於能讓別人死了，但我還算人嗎？
```

## 全書主題遞進

正式版最核心的主題曲線仍然是：

```text
自己死 → 看別人死 → 讓別人死
```

五章則負責把這條曲線逐步推進：

- 第一章：自己死。玩家用一條條命學會世界不是給凡人準備的。
- 第二章：進門後被使用。仙門真的需要你，但需要的是你的時間、肩膀與風險承擔能力；同時開始看見別人的事故如何變成規矩與紀錄。
- 第三章：看別人死＋機緣判斷。玩家第一次真正站在「活著的那個」位置，看別人先碰靈藥、先踩秘境、先試古丹、先信殘魂、先被推去探路；他們的死會變成情報、避險依據，甚至讓玩家更接近機緣。
- 第四章：因果套娃。玩家終於有籌碼，也因此第一次變成別人關係網裡值得追索的「小的」。
- 第五章：讓別人死。玩家終於有能力主動安排別人承擔風險，卻也開始接近自己曾經痛恨的修仙者。

核心命題：

> 弒龍者終成惡龍。

但本作不能把這句做成單純黑化爽感，而是要讓玩家一步一步理解：不是主角想變壞，而是這個世界會獎勵把危險推給別人的人。

## 字數規格

每章目標約五萬字，包含：

- 主線事件文本。
- 可重複事件變體。
- 隱藏真相池。
- 觀察、打聽、延後、放棄等策略分支。
- 死亡描述。
- 墓誌銘。
- 死後世界情報。
- 少量跨章伏筆。

五萬字不是線性劇情長度，而是事件池容量。玩家單局仍然應該短，文本量主要來自多世輪迴、多真相變體與不同死法。

## 第一章：村外有仙

玩家狀態：普通凡人、山村少年、家境與身體條件不穩定。

核心體驗：玩家第一次接觸仙途，學會「機緣不一定是好事」。

主題位置：自己死。

主要內容：

- 山村生活。
- 出身與家境。
- 靈根傳聞。
- 青雲宗招雜役。
- 山中靈草。
- 遊方散修。
- 少量開局殺與少年期事故。

第一章的死亡不能只是懲罰錯選項，而要建立世界規則：凡人沒有資訊、沒有背景、沒有靈根、沒有錢，所以同樣一件小事，對凡人就是會死。

## 第二章：山門不渡凡人

玩家狀態：宗門招募者、落選者、雜役、外門邊緣人。

核心體驗：宗門不是慈善機構，進去不代表活下來。

主要內容：

- 靈根測試。
- 雜役選拔。
- 靈石搬運。
- 藥田差事。
- 師兄利用。
- 外門規矩。
- 殘缺功法。
- 被收下後才發現自己只是宗門耗材。

第二章要讓玩家明白：進門不是勝利，只是換一種死法。

## 第三章：藥谷秘境，機緣皆是殺局

玩家狀態：記名／外門弟子，第一次真正有資格接觸能改命的宗門資源。

核心體驗：修仙世界最可怕的不是沒有機緣，而是你分不清哪個機緣是餌。

章節定位：中期爆點章。玩家第一次有機會拿到真正改命資源，但每個機緣背後都有代價。

主題位置：**看別人死。**「機緣判斷」是本章的玩法核心；「看別人死」是情緒與倫理核心。別人先踩雷後，玩家會得到更完整的情報、更安全的路線，甚至空出的名額與機緣，因此第一次清楚感受到：自己活下來、變聰明、離寶物更近，有時真的建立在別人的死上。

五段主結構：

- 3-1 藥谷徵召：約 10,000 字。外門弟子被徵召進藥谷，表面是福利；名額、準備與歷年死傷都能調查。
- 3-2 靈藥異變：約 10,000 字。靈藥成熟，妖獸、師兄、管事與污染同時盯上資源。
- 3-3 秘境開口：約 10,000 字。玩家可進入、逃避、調查、延遲、交易名額與情報，不做單純進／不進二選一。
- 3-4 真正機緣：約 10,000 字。功法、丹藥、殘魂、古物都可能是真的，同時各有副作用、污染或所有權代價。
- 3-5 活著出谷：約 10,000 字。不一定拿最多才算贏；活著、保留退路並帶出正確情報也能改命。

主要場景：宗門藥谷、封印洞府、低階秘境、散修屍地、妖獸巢穴。

代表死法：被靈藥寄生、被隊友推去探路、拿到殘缺功法走火入魔、相信秘境老者遭奪舍、逃避秘境後被評等與資源分配秋後清算。

新增系統：機緣污染、秘境情報、物品鑑別、臨時隊友、背叛風險。

本章要教玩家：

- **別人的死是情報，但不是答案。** 前一個人死在某件機緣上，只代表風險被看見了一部分；下一世或下一次同類事件仍可能有不同真相。
- **看別人死會讓你更安全，也可能讓你更接近機緣。** 這份收益必須讓玩家感到不舒服，才能銜接第五章主動把風險推給別人。
- 機緣不是獎勵，而是測試。
- 貪會死，不貪也可能失去翻身機會。
- 觀察、延遲、交易、準備，比單純選「拿／不拿」更重要。
- 同一件機緣在不同世界線可是真寶、污染物、半真殘缺品或需要特定條件才能安全使用，不能靠死亡背固定答案。

## 第四章：套娃追殺

玩家狀態：少數接近真仙途門檻的人，或在某次輪迴中短暫獲得籌碼的小人物。

核心體驗：玩家以為自己打倒了眼前壓迫者，卻發現那只是更大壓迫鏈條的一環。

套娃概念：

```text
打了小的 → 來了老的 → 老的背後還有宗門 → 宗門背後還有更大的利益
```

但這一章的反轉是：

```text
今天的小的，就是主角自己。
```

玩家不再只是被妖獸、騙子、師兄欺負，而是開始被更高層級的修仙者視為「某個人要保的小輩」、「某條利益線上的小角色」、「不能被隨便打死但可以被慢慢榨乾的人」。

主要內容：

- 替人背鍋。
- 被上層修士當作小輩棋子。
- 打死敵人後引來師父、家族、宗門、債主。
- 贏了眼前事件，輸了整條因果鏈。
- 第一次擁有籌碼，但籌碼也會變成追殺理由。

第四章不是爽文打臉，而是把爽文打臉拆成恐怖生存：你以為你打的是雜魚，其實你碰的是整個世界的關係網。

## 第五章：你還想修嗎

玩家狀態：真正摸到修仙門檻的人，或終於理解這套世界規則的人。

核心體驗：第一次真正有能力讓別人替自己承擔危險，但必須決定是否繼續往上爬。

主題位置：讓別人死。

主要內容：

- 苟活凡人結局。
- 半吊子散修結局。
- 宗門耗材結局。
- 看破修仙結局。
- 真入仙門極罕見結局。
- 死在成功前一刻。
- 把危險推給別人後活下來。
- 成為自己曾經痛恨的那種人。

第五章不是打王破關，而是價值選擇。

> 你知道修仙到底是什麼了。  
> 你還要不要進去？

## 第一章實作提醒

雖然目前開發從第一章開始，但第一章不能只做成短篇試玩。第一章事件資料必須保留五萬字章節容量，包括：

- 至少四條主事件線：山村少年、青雲宗、山中靈草、遊方散修。
- 每條主事件線都要有多個表面相同但背後不同的真相。
- 每條線都要能產出多種死亡、殘廢、失去資格、苟活、錯失機緣結果。
- 墓誌銘與死後情報要支撐玩家多次輪迴。
- 第一章要埋入第三章「機緣可能是真的，也可能是餌」與第五章「讓別人死」的早期伏筆。
